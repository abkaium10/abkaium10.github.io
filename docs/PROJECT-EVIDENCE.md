# Project evidence ledger

Project metadata is validated by `npm run validate:evidence`. Existing project cards remain the primary presentation; optional `evidence` fields can point to repository, demo, tests, architecture, benchmark, API contract, and known limitations. Only add links that exist and can be verified. Missing evidence should remain missing, not be replaced with invented metrics. Automated link checks verify reachability at a point in time and do not prove ownership, correctness, or production quality.
